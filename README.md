# CodeAlpha - Student Grade Tracker

## Project Overview
The Student Grade Tracker is a Java-based console application developed as part of the CodeAlpha Java Programming Internship.

This application allows users to manage student records, calculate average marks, identify the highest and lowest scores, and display all student details using Object-Oriented Programming (OOP) concepts.

## Features
- Add Student Records
- Display All Students
- Calculate Average Marks
- Find Highest Marks
- Find Lowest Marks
- Menu-Driven Console Application
- Uses ArrayList for Data Storage
- User Friendly Console Interface

## Technologies Used
- Java
- NetBeans IDE 22
- Object-Oriented Programming (OOP)
- ArrayList
-Java Collection

## How to Run

1. Open the project in NetBeans IDE.
2. Run the `Main.java` file.
3. Select an option from the menu.
4. Add student details and view the results.
